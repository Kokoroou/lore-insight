RPG Maker event viewer FAQ

MakerLens Events shows the events of an RPG Maker MV or MZ game as a flow graph, right in your browser: dialogue, choices, conditions, labels and jumps. It works on released games, with no editor and no plugin. Your files never leave your device.

Opening a game

How do I view the events of an RPG Maker MV or MZ game?

Open MakerLens Events, press Select Game Folder and pick the game's folder, or drop the folder anywhere on the page. Pick a map in the sidebar, then an event: its commands appear as a flow graph. Click a node to read its full text in the side panel, and use the page tabs for events with more than one page.

Which folder do I select?

The game's root folder works, and so does its data/ folder on its own. MV games keep it in www/data/, MZ games in data/; MakerLens Events finds either. It reads MapInfos.json (the map tree), every Map###.json, CommonEvents.json, System.json (switch and variable names) and Actors.json. Images and audio are not needed.

Do I need the RPG Maker editor, the project file or a plugin?

No. It reads a released game as it is shipped, so you don't need to own RPG Maker, open the project or start a playtest. That is the difference from node editors and debugger plugins, which run inside the game or the editor. Nothing is installed into the game, and the game is never changed.

Which RPG Maker versions are supported?

RPG Maker MV and MZ, whose event data is plain JSON. XP, VX and VX Ace store events in Ruby files (.rxdata, .rvdata, .rvdata2) and are not supported yet, nor are RPG Maker 2000 / 2003. For the images and audio of XP, VX and VX Ace games, use MakerLens Assets.

Why does it say “No RPG Maker data folder found”?

It found no data/ folder and no Map###.json file in what you selected. Select the game's root folder (the one with Game.exe) or its data/ folder, not img/ or audio/. Some released games pack all their files into the .exe or encrypt data/ with a plugin; MakerLens Events cannot read those.

Reading the graph

What does the flow graph show?

Five kinds of node: dialogue (Show Text, with the speaker name in MZ), choices (Show Choices, one branch per option), conditions (Conditional Branch, with its Else branch), labels, and jumps to a label, drawn as dashed arrows. Other commands, such as Control Switches, Transfer Player, a Common Event call or a script, are not drawn yet.

How do I find what unlocks an ending or a hidden route?

Open the event that starts the ending and follow its condition nodes: each one names the switch, variable or actor it tests, such as If [Switch: Met the witch]. Then look for the event that leads into that branch. Note that the conditions on an event page's own settings (the editor's page conditions) are not shown yet; switch between the page tabs to compare pages.

Are switch, variable and actor names shown?

Yes. Names come from the game's System.json and Actors.json, so a condition reads If [Variable: Gold found] rather than a bare number. In dialogue, the \N[n] and \V[n] text codes are replaced with the actor name and the variable name. A switch without a name shows its number instead, such as If [Switch #12].

Can I see common events?

Yes. Common events are listed below the maps in the sidebar and open as graphs the same way. Maps keep the tree and folder order of the editor, from MapInfos.json.

Which branch does a line of dialogue belong to?

Find the line's dialogue node and follow the arrows back up: the choice option or the If / Else branch above it is the branch. Click any node to read the full text in the side panel. This is handy for translators who need to know when a line is said.

Privacy, editing and legal

Can I edit events or export them?

No. MakerLens Events is read-only: it never writes to the game files and has no export. To change events, use the RPG Maker editor. You can drag nodes to tidy the graph (with undo and redo), but that only changes what you see.

Are my game files uploaded anywhere?

No. Files are read by your browser and never leave your device. The page's Content-Security-Policy blocks requests to any server except an anonymous page-view counter, which receives only the page address and referrer, and the optional feedback form, which sends only the rating and comment you choose to send. Details: Privacy & analytics.

Do I need to install anything? Does it work offline?

No installation and no account. It works best in Chrome or Edge; Firefox works too, through its folder picker. All libraries are served from this site, so once the page has loaded it works without an internet connection. The source code is on GitHub (MIT license).

Is it legal to look at a game's events?

MakerLens Events only reads files that are already on your computer and changes nothing. It is meant for your own games, or games you have permission to study, for example to write a guide or a translation. Reusing a game's story or text elsewhere may need the rights holder's permission, so check the game's terms.

How do I get a game's images and music?

Use MakerLens Assets, the other MakerLens tool. It opens the same game folder and previews and downloads its encrypted images and audio (.rpgmvp, .png_, .ogg_ and more), also in your browser.
