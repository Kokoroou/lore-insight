MakerLensEvents
RPG Maker event flow viewer — part of MakerLens
How to Use
  • Click Open Folder and select your RPG Maker game's root folder (or its data/ subfolder).
  • Pick a map from the sidebar, then click an event to view its command flow as a node graph.
  • Use page tabs to switch between event pages. Click any node to inspect its full content in the right panel.
  • Common Events are listed below the maps in the sidebar.
