MakerLensEvents

RPG Maker event flow viewer — part of MakerLens
How to use
  1. Click Open Folder and select your RPG Maker game's root folder (or its data/ subfolder).
  2. Pick a map from the sidebar, then click an event to view its command flow as a node graph.
  3. Use the page tabs to switch between event pages. Click any node to inspect its full content in the right panel.
  4. Common Events are listed below the maps in the sidebar.
  5. Type in the search box at the top of the sidebar (or press /) to find scenes and events by name.
  6. Scenes (pictures with dialogue) are listed at the top of the sidebar: click one, or press Preview, to play it like in the game.

Want the game's images and music? Open MakerLens Assets.

Questions? Read the FAQ: which folder to open, what the graph shows, privacy.
